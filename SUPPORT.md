# Support

Thanks for using Scrape.do. Here is where to go for what.

| I need… | Go to |
|---------|-------|
| API documentation, parameters, examples | [scrape.do/documentation](https://scrape.do/documentation) |
| Help with my account, plan, credits or billing | [support@scrape.do](mailto:support@scrape.do) |
| A bug in one of these repositories | the repository's **Issues** tab (use the bug report template) |
| A feature or an improvement | the repository's **Issues** tab (use the feature request template) |
| To report a security vulnerability | **not** an issue: see [SECURITY.md](SECURITY.md) |

## Before opening an issue

- Search the existing issues, including closed ones.
- Reproduce with the latest release of the project.
- Never paste your API token, a URL that contains it, or any other credential
  into an issue. Redact it; the maintainers never need it.

## Questions about scraping a particular site

The GitHub issue trackers are for the code in each repository: the SDKs, the
CLI and the MCP server. Questions about why a particular target site blocks,
about proxies, geo-targeting or rendering options belong to
[support@scrape.do](mailto:support@scrape.do), where the team can look at your
account and the request itself.
